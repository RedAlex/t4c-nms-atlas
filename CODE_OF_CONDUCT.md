# Code de conduite

Nous voulons un projet accueillant, respectueux et utile.

## Nos engagements

- Respect mutuel
- Communication constructive
- Ouverture a la critique technique
- Zero harcelement

## Comportements inacceptables

- Attaques personnelles
- Harcelement, intimidation, discrimination
- Publication d'informations privees sans accord
- Spam ou sabotage volontaire

## Application

Les mainteneurs peuvent moderer, masquer ou refuser les contributions qui ne respectent pas ce cadre.
